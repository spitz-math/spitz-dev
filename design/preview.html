hierarchy

  1. neutral structure — almost everything on screen
  2. identity — who it belongs to: spitz/Kody orange, The Void violet, ChatGPT cyan, Claude crimson
  3. status — what state it is in, always icon + word
  4. interaction — what you can do
  5. auxiliary — charts and art, no meaning
  6. atmosphere — tonal overlays, no meaning

When rules conflict: accessibility > status meaning > identity > brand > decoration.

0 · neutrals

1 · identity

Each identity has a base (fills, big marks), a -text shade for small text and a -line shade for borders. Claude crimson is too dark for small text or thin borders on these surfaces, so it shows up as a fill or a 4px edge, with #E77791 for text and #D0445F for borders.

2 · status

Status colors are softer than identity colors so they never read as an agent. Mint ≠ reserved green, amber ≠ reserved yellow, rose ≠ Claude crimson. The icon and word carry the meaning; the color only helps.
